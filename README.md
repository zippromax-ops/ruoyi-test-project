# RuoYi-Vue 后台管理系统 - 手工测试项目

## 📖 项目简介
本项目是针对 RuoYi-Vue 开源后台管理系统进行的手工功能测试实践，旨在通过系统的测试流程，验证系统核心模块的稳定性和功能性。

## 🎯 测试范围
| 模块 | 测试内容 | 用例数 |
|------|----------|--------|
| 登录模块 | 正常登录、异常登录、验证码校验 | 20 |
| 用户管理 | 用户查询、新增、修改、删除、重置密码 | 8 |
| 角色管理 | 角色查询、新增、修改、删除 | 6 |

## 📁 项目结构
├── README.md # 项目说明
├── testcases/ # 测试用例
│ └── 用户管理模块测试用例.xlsx
├── bug_reports/ # 缺陷报告
└──── 缺陷跟踪记录.xlsx

## ✨ 测试成果
- 设计并执行 **30+ 条** 手工测试用例
- 覆盖 **用户管理、登录认证、角色权限** 3 个核心模块
- 发现并跟踪 **2 个** 有效缺陷
- 编写详细测试报告，推动问题修复闭环

## 🛠️ 测试环境
- 被测系统：RuoYi-Vue v3.8.8
- 部署环境：CentOS 7 + MySQL 5.7 + Redis
- 测试工具：Chrome DevTools（抓包）、Excel（用例管理）、Postman（接口测试）
